# Expense Tracker and Financial Analysis System

## Project Overview
This is a Python-based application that helps users manage daily expenses, analyze spending patterns, and understand their financial habits. It uses MySQL to store expense records and includes an AI-powered chatbot for answering expense-related questions.

## Features
- Add and view expenses
- Store expense records in MySQL
- Analyze expenses by category and date
- Visualize spending patterns using charts
- Export expense data
- Ask expense-related questions using an AI chatbot
- Validate inputs and handle errors

## Technologies Used
- Python
- MySQL and SQL
- Pandas
- NumPy
- Matplotlib
- Gemini API
- Git and GitHub

## Project Files
- `main.py` - Main application
- `database.py` - Database operations
- `expense.py` - Expense functionality
- `analysis.py` - Expense analysis
- `visualization.py` - Charts and visualizations
- `export.py` - Data export
- `chatbot.py` - AI chatbot
- `requirements.txt` - Required Python packages

## How to Run
1. Install Python and MySQL.
2. Install dependencies using `pip install -r requirements.txt`.
3. Create and configure the MySQL database.
4. Configure the Gemini API key if you want to use the chatbot.
5. Run the application using `python main.py`.
